How to record

Each row is one hour. Patients is the number of people. Acute is the number of acute scripts. Under Chronic, each number is how many chronic scripts had that many items. 9+ means 9 or more. Under ARV, 1, 2 and 3 are how many ARV scripts had that many items. Scripts is acute + chronic + ARV. Arrow keys move across the grid. Enter moves down. Numbers save on this device as you type. Last backup: not yet

When this page is open at the backup time, or the next time you open it that day, a full history file is written to Downloads as Montebello-Stats-Backup-YYYY-MM-DD.json. A copy is also kept here so you can download it again. A closed page cannot back itself up, so open the file at least once each day.

Keep this file’s name and folder the same. Saved statistics are tied to this file’s location. If you rename or move it, the days will not show until you move it back or restore a JSON backup.
